What is a base?

In base b there are b digits, 0 to b − 1, and the digit in position k counts units of bk: x = Σ dk bk. The base changes how a number is written, not the number itself. Step through the conversion: from the largest place value down, each digit is how many times bp fits in what is left of x, dp = ⌊x / bp⌋; subtract dp bp and move to the next place, bp−1. The digits come out left to right, through the point.
